### 🧩 구문 — 학술 지문 고난도 문장 구조 140개

학술 지문에서 반복해 나오지만 단어를 다 알아도 해석이 막히는 **문장 구조**를 모았습니다.
**구조 유형 13종 × 주제 13종**으로 교차 분류되어, "도치만 몰아서" 또는 "생물·의학 주제 예문만" 같은 식으로 좁혀 볼 수 있습니다.

| 구조 유형 | 개수 | 대표 구조 |
|-----------|-----:|-----------|
| 도치·강조 | 12 | `Not only did ~`, `So + 형용사 + be + S + that`, `It is X that ~` |
| 비교·대조 | 12 | `The 비교급 ~, the 비교급 ~`, `not so much A as B`, `no more A than B` |
| 관계절 | 11 | `전치사 + which/whom`, `the extent to which`, `수량사 + of which` |
| 삽입·동격 | 11 | 동격의 that, `few, if any`, 대시 삽입 + 독립분사 |
| 부정 표현 | 11 | `by no means`, `anything but`, 이중부정, 부분부정 |
| 목적·조건 | 11 | `lest + 동사원형`, `Should + 주어` (if 생략), `so as not to` |
| 학술 관용표현 | 11 | `in light of`, `on the grounds that`, `at odds with`, `bear on` |
| 담화 표지 | 11 | `albeit`, `Notwithstanding`, `insofar as`, `That said` |
| 분사구문 | 10 | 완료 분사구문, 독립분사구문, `with + 명사 + 분사` |

- 🎯 **문제 풀기** — 핵심부를 빈칸으로 가리고 4지선다로 출제합니다. 오답 보기는 **어순·전치사·활용형만 살짝 틀어** 만들어서 감으로 찍기 어렵습니다
  - 채점하면 빈칸에 정답이 채워져 **구조가 완성된 모습**을 그대로 보여 주고, 구조명·해석·설명이 함께 펼쳐집니다
  - 결과 화면에 **틀린 구문 목록**(구조명 + 유형) 표시
  - 어휘 퀴즈·문법과 같은 **콤보 시스템** 적용 (기록은 따로 저장)
- 🎚 **난이도 × 구조 유형 × 주제 3축 교차 필터** — 한 축을 고르면 나머지 두 축의 개수가 실시간으로 다시 계산됩니다
- 🔎 구조명·예문·해석·설명 전체 검색 (예: `도치`, `whereas`, `가정법`)

### 🎬 장르·슬랭 — SF·판타지 / 힙합 / 스트리트 150개

시험 영어만으로는 안 잡히는 영역입니다. **SF·판타지**는 소설·게임·드라마를 읽고 보는 데, **힙합·스트리트 구어**는 가사와 실제 대화를 알아듣는 데 필요합니다.

**이 탭의 핵심은 `사용 등급`입니다.** 뜻만 알고 아무 데서나 쓰면 곤란해지는 말이 섞여 있어서, 150개 전부에 등급을 붙였습니다.

| 등급 | 개수 | 의미 |
|------|-----:|------|
| 🟢 **어디서나** | 80 | 직장·시험·처음 만난 사람에게도 무난. 대부분 표준 어휘 |
| 🟡 **친한 사이** | 59 | 또래끼리는 자연스럽지만 격식 있는 자리에서는 쓰지 말 것 |
| 🔴 **이해만** | 11 | 뜻은 알되 직접 쓰지 말 것. 흑인 영어(AAVE) 고유 표현이거나, 비원어민이 쓰면 흉내처럼 들려 무례해지기 쉬운 말 |

| 영역 | 개수 | 분류 (각 10개) |
|------|-----:|----------------|
| 🛸 **SF·판타지** | 50 | 세계관·배경 / 존재·종족 / 마법·능력 / 기술·장치 / 서사·전개 |
| 🎤 **힙합** | 50 | 랩 기술 / 음악 제작 / 씬·문화 / 갈등 / 자랑·성공 |
| 🏙 **스트리트** | 50 | 감정·반응 / 사람·관계 / 상황·평가 / 약속·행동 / 말투·어법 |

- 📚 **단어·표현 보기** — 표제어·뜻·등급이 접힌 채로 보이고, 누르면 영영뜻·예문·예문 해석·**사용법 주의점**이 펼쳐집니다. 예문에서 그 표현이 쓰인 자리에 강조가 들어가고, 🔊 예문 듣기를 지원합니다
- 🎯 **퀴즈** — 예문 빈칸 채우기와 뜻 고르기를 섞어 냅니다. 오답 보기는 **같은 영역에서** 뽑아서(SF 문제에 스트리트 슬랭이 섞이면 몰라도 걸러지므로) 실제로 뜻을 알아야 풀립니다. 채점하면 **등급 배지와 사용법이 함께** 나옵니다
- 🎚 영역 × 분류 × 사용 등급 3축 필터 + 한글·영문 전체 검색
- **말투·어법** 분류에는 `ain't`, `y'all`, `gonna`, 이중 부정, habitual `be`처럼 가사·드라마 듣기에 꼭 필요한 축약과 방언 문법을 담았습니다. '틀린 영어'가 아니라 다른 말투라는 점, 그리고 알아듣기용이라는 점을 함께 설명합니다

> ⚠️ 인종적 멸칭(n-word)은 등급을 매길 대상이 아니라서 **애초에 수록하지 않았습니다.** 가사에 나오더라도 비흑인은 따라 부르기를 포함해 어떤 경우에도 쓰지 않는 것이 원칙이며, 앱 안에서도 그렇게 안내합니다.

### 🦉 듀오링고 영어 테스트(DET) — 유형별 실전 연습

DET는 문제 형식이 토익·토플과 완전히 달라서 형식 자체에 익숙해지는 것이 핵심입니다. 실제 출제 유형 그대로 구현했습니다.

| 유형 | 형식 | 분량 |
|------|------|-----:|
| 🔤 **Read and Select** | 9개 단어 중 **실제 존재하는 영단어**만 고르기 | 실단어 473 + 가짜 181 |
| ✏️ **Read and Complete** | 지문에서 **글자가 지워진 단어** 채우기 (c-test) | 30지문 · 빈칸 150개 |
| 🎧 **Listen and Type** | 문장을 듣고 **그대로 받아쓰기** | 65문장 |
| 📖 **Complete the Passage** | 지문 빈칸 4지선다 (Interactive Reading) | 30문항 |
| 🗣 **Speaking · Writing** | 사진 묘사·읽고 쓰기·듣고 말하기·대화 요약 **모범답변** | 25문항 |

- **Read and Select** — 가짜 단어 181개는 영어 음운 규칙에 맞게 만들었고, 실제 어휘 1,421개와 **충돌 0건**을 자동 검증했습니다. 채점 시 🟢 맞게 고름 / 🔴 가짜를 고름 / 🟠 놓친 실제 단어로 구분 표시
- **Read and Complete** — 빈칸마다 글자 수만큼 칸이 좁혀지고, `Enter`로 다음 빈칸 이동. 틀리면 정답을 옆에 초록색으로 표시하고 지문 해석 제공
- **Listen and Type** — TTS로 재생하며 **실제 시험처럼 재생 3회 제한**. 🐢 느리게 듣기 지원. 채점은 단어 단위로 비교해 일치/불일치를 색으로 표시
- **Speaking · Writing** — Write About the Photo / Read, Then Write / Speak About the Photo / Read, Then Speak / Listen, Then Speak / Summarize the Conversation / Interactive Writing 7개 유형. 각 문항에 영문 모범답변 · 한글 해석 · 핵심 표현 · 고득점 팁 · 원어민 음성 재생


### 🎧 음성 — 브라우저에서 돌아가는 오픈소스 TTS (Piper)

브라우저 내장 음성(`speechSynthesis`)은 OS가 직접 소리를 내는 방식이라 **음성을 파일로 저장할 수 없습니다.**
그래서 오픈소스 TTS인 **[Piper](https://github.com/rhasspy/piper)** 를 onnxruntime-web으로 **브라우저 안에서 직접 실행**하도록 붙였습니다.

| 항목 | 내용 |
|------|------|
| 엔진 | Piper (VITS) · `@diffusionstudio/vits-web` |
| 실행 위치 | **100% 브라우저** — 텍스트가 서버로 전송되지 않음 |
| 영어 음성 | 미국 5종 · 영국 3종 (여성/남성, 북부 억양 포함) |
| 모델 | 음성당 약 60MB, **최초 1회만** 내려받고 브라우저에 캐시 → 이후 오프라인 동작 |
| 출력 | **WAV 파일** — 재생과 다운로드 모두 가능 |
| 속도 | 문장 1개 약 2초, 250단어 지문 약 40초 (캐시 후) |

- 헤더의 🎙 버튼에서 **브라우저 기본** ↔ **고품질(Piper)** 전환, 음성·재생 속도 선택, 미리 듣기, 받아 둔 모델 삭제
- 긴 지문은 문장 단위로 나눠 합성한 뒤 하나의 WAV로 이어 붙입니다
- ⬇ **음성** 버튼: 관심주제 지문 · 스피킹/라이팅/리딩 모범답변 · 듀오링고 Speaking·Writing 모범답변
- 📄 **대본** 버튼: 엔진과 무관하게 지문·답변·해석을 .txt로 저장 (다른 TTS 도구에 넣어 쓸 수 있음)
- Piper 실패 시 자동으로 브라우저 음성으로 넘어갑니다

### 📱 모바일 대응

- 탭 12개는 가로 스크롤 — **선택한 탭이 항상 화면 안으로 자동 스크롤**되고, 양옆에 더 있다는 것을 **페이드**로 표시
- 375px 기준 **12개 탭 전체를 자동 검사**해 가로 넘침 0건 · 터치 영역 30px 미만 0건 확인
- 좁은 화면에서 지문·보기·카드 여백과 글자 크기를 줄이고, 헤더 부제를 숨겨 한 줄로 유지

### ℹ️ 시험 정보 페이지

**TOEFL iBT · Duolingo · TOEIC · TOEIC Speaking · OPIc · TEPS** 6개 시험의 정보를 정리했습니다.

- 시험별 상세 카드 — 총 시간 · 점수 체계 · 유효기간 · 응시 방식 · 주요 용도
- **구성표** — 영역별 문항 수와 시간, 세부 내용 (예: TOEIC Part 1~7, TOEFL 4개 영역, TEPS 4개 영역)
- **출제 유형**과 **알아두면 좋은 점**(개편 사항, 시간 배분 전략, 등급 기준선 등)
- 📊 **한눈에 비교** — 6개 시험을 가로 스크롤 표 하나로 비교

### 🔥 콤보 시스템 — 어휘 퀴즈 · 문법 · 구문 · 슬랭 · DET 공통

연속으로 맞힐수록 등급이 올라가며, **자기 최고 기록을 깨는 재미**로 승부욕을 자극합니다.

| 연속 | 등급 | 연출 |
|-----:|------|------|
| 2 | 🔥 콤보 시작 | 배지 등장 |
| 3 | 🔥 **불붙었다** | 화면 중앙 `3 COMBO` 팝업 + 색종이 증가 |
| 5 | ⚡ **무서운 기세** | 보라 등급 배지 + `5 COMBO` 팝업 |
| 7 | 💎 **완벽 모드** | 파랑 등급 배지 + `7 COMBO` 팝업 |
| 10 | 🌟 **압도적** | 색종이 대량, 이후 5의 배수마다 팝업 |
| 15 | 👑 **전설** | 배지가 빛나는 애니메이션 |

- 🏆 **개인 최고 기록** — 어휘 퀴즈 · 문법 · DET **각각 따로** `localStorage`에 저장. 점수 옆에 `· 최고 🔥7`로 항상 표시
- 기록을 넘어서는 순간 **🏆 신기록** 태그 + 대량 색종이. 단, 한 연속당 **한 번만** 축하해 남발하지 않음
- 콤보가 쌓일수록 **효과음 음이 반음씩 올라가** 상승감을 줌 (최대 1옥타브)
- 결과 화면에 `이번 판 최고 콤보` / `개인 최고 기록` 비교와 **"기록 경신까지 N연속 남았어요!"** 안내
- 오답이면 콤보 초기화 — 다시 도전하면 그 연속에서 신기록을 노릴 수 있음

### 🖨 인쇄·PDF / 📊 엑셀(CSV) 내보내기

단어장 탭의 내보내기 바에서 **전체가 아니라 원하는 범위만** 뽑아냅니다.

| 버튼 | 동작 |
|------|------|
| ☑ **선택 모드** | 단어 왼쪽에 체크박스 표시 — 원하는 단어만 골라 담기 |
| **전체 선택 / 선택 해제** | 현재 필터 결과 전체를 한 번에 선택/해제 |
| ✍️ **시험지형** | 뜻 칸을 **빈칸**으로 출력해 직접 써보는 시험지로 인쇄 |
| 🖨 **인쇄 · PDF** | A4 표로 인쇄 — 인쇄 창에서 *대상: PDF로 저장* 선택하면 PDF |
| 📊 **엑셀(CSV)** | `vocab_날짜_개수.csv` 다운로드 (BOM 포함 → 엑셀에서 한글 안 깨짐) |

- **범위 규칙:** 체크한 단어가 있으면 **그 단어만**, 없으면 **현재 난이도·주제·검색 필터 결과 전체**가 대상입니다. 버튼 옆에 대상 개수(`선택 12개 내보내기` / `현재 목록 158개 내보내기`)가 항상 표시됩니다.
- 인쇄물 머리말에 조건이 함께 찍힙니다 — 예: `최고급 · 과학·기술 · 총 9개 · 2026-07-26`
- 인쇄 컬럼: `# / Word / 품사 / 난이도·주제 / 뜻·영영뜻(또는 빈칸) / 예문`
- CSV 컬럼: `No, Word, POS, 뜻, 영영뜻, 예문, 난이도, 주제, 외움, 즐겨찾기`

## 📝 데이터 추가/수정

**문법 문제** — `grammar.js` 배열에 추가 (`q`의 빈칸은 `----`, `ans`는 정답 보기의 인덱스)

**장르·슬랭** — `slang.js` 배열에 추가. `blank`는 `ex` 안에 그대로 있는 부분 문자열이어야 하고, `reg`(사용 등급 1/2/3)는 필수입니다.

**구문** — `structures.js` 배열에 추가. `blank`는 **`en` 안에 그대로 들어 있는 부분 문자열**이어야 하며(그 자리가 빈칸이 됨), `opts`에는 오답 보기 3개만 넣습니다(정답은 `blank` 자신).
```js
{ id: 301, cat: "관계사", sub: "주격", q: "The engineer ---- designed it will lead the training.",
  opts: ["who","whom","whose","which"], ans: 0,
  ko: "그 시스템을 설계한 엔지니어가 교육을 이끌 것이다.",
  exp: "사람 선행사 + 뒤에 동사가 이어지므로 주격 관계대명사 who.", level: 1 }
```

**단어** — `words.js` 배열에 추가
`level`: 1=기초, 2=중급, 3=고급, 4=최고급 / `topic`: 위 13종 중 하나(정확히 일치해야 필터에 잡힘)
```js
{ word: "mitigate", pos: "v.", en: "to make less severe", ko: "완화하다",
  ex: "Trees can mitigate heat.", level: 2, topic: "변화·수량" }
```

**문항** — `speaking.js` 배열에 추가
(`exam`: `OPIc` | `TOEIC` | `TOEFL` | `TOEFL Writing` | `TOEFL Reading`)
```js
{ exam: "OPIc", category: "여가활동", topic: "영화 보기", question: "...", targetLevel: "IH–AL",
  answerEn: "...", answerKo: "...", keyExpressions: [{en:"...", ko:"..."}], tips: "..." }
```
지문·보기처럼 줄바꿈이 필요한 곳은 `\n`을 쓰면 화면에서 줄바꿈으로 표시됩니다.
