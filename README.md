**난이도 4단계·주제별 TOEFL 어휘 1,056개** + **오픽(OPIc)·토익스피킹·토플 스피킹/라이팅/리딩 문항 386개**로 공부하는 영어 학습 웹앱입니다.

- 🎚 **난이도 × 주제 교차 필터** — 카드·퀴즈·단어장 각각 독립 적용. 한쪽을 고르면 다른 쪽 개수가 실시간으로 다시 계산됨 (예: `최고급 × 과학·기술 = 9개`)
- 🃏 **플래시카드** — 카드 뒤집기, 발음 듣기(TTS), 외움/즐겨찾기, 셔플
- ✍️ **퀴즈** — 4지선다 10문항, 즉시 채점 + 정답 해설(단어·뜻·영영뜻·예문·발음)
  - 🔤 **단어 → 뜻** / 🇰🇷 **뜻 → 단어** / 🔀 **혼합** 세 방향 선택
  - 보기(오답)는 같은 난이도에서 우선 추출, 뜻이 겹치지 않게 구성
  - 🎉 **정답 연출** — 색종이가 터지고 보기가 튀어오르며 효과음 재생, 점수가 팝업, 진행바가 즉시 채워짐
  - 🔥 **연속 정답(콤보)** — 2연속부터 배지 표시, 3·5연속에서 색종이 양이 늘어남. 결과 화면에 최고 콤보 기록
  - ❌ **오답 연출** — 보기가 좌우로 흔들리고 낮은 효과음, 콤보 초기화
  - 🔊 **효과음 on/off** 토글 (선택 저장). 파일 없이 WebAudio로 즉석 생성
  - 📍 **다음 버튼 고정** — 보기 바로 아래 항상 같은 자리(픽셀 단위 고정), 정답 해설은 버튼 **아래**로 펼쳐져 버튼을 찾아 스크롤할 필요 없음
  - ⌨️ **키보드만으로 진행** — `1`~`4` 답 고르기, `Enter`(또는 `Space`·`→`) 다음 문제, 결과 화면에서 `Enter` 다시 풀기
  - `prefers-reduced-motion` 설정 시 애니메이션·색종이 자동 비활성화
- 📚 **단어장** — 검색(주제명 검색 포함), 외움/즐겨찾기/난이도/주제 필터
  - 🗂 **카드형** / ☰ **목록형** 보기 전환 (선택한 보기 기억됨)
  - 목록형은 한 줄에 `단어 – 뜻`, 행을 누르면 영영뜻·예문 펼침
  - 🙈 **뜻 가리기** — 뜻을 흐리게 처리해 셀프 테스트, 누르면 해당 단어만 공개
- 📊 진행률 자동 저장(`localStorage`)

### 🖨 인쇄·PDF / 📊 엑셀(CSV) 내보내기

단어장 탭의 내보내기 바에서 **전체가 아니라 원하는 범위만** 뽑아냅니다.

| 버튼 | 동작 |
|------|------|
| ☑ **선택 모드** | 단어 왼쪽에 체크박스 표시 — 원하는 단어만 골라 담기 |
| **전체 선택 / 선택 해제** | 현재 필터 결과 전체를 한 번에 선택/해제 |
| ✍️ **시험지형** | 뜻 칸을 **빈칸**으로 출력해 직접 써보는 시험지로 인쇄 |
| 🖨 **인쇄 · PDF** | A4 표로 인쇄 — 인쇄 창에서 *대상: PDF로 저장* 선택하면 PDF |
| 📊 **엑셀(CSV)** | `vocab_날짜_개수.csv` 다운로드 (BOM 포함 → 엑셀에서 한글 안 깨짐) |

- **범위 규칙:** 체크한 단어가 있으면 **그 단어만**, 없으면 **현재 난이도·주제·검색 필터 결과 전체**가 대상입니다. 버튼 옆에 대상 개수(`선택 12개 내보내기` / `현재 목록 158개 내보내기`)가 항상 표시됩니다.
- 인쇄물 머리말에 조건이 함께 찍힙니다 — 예: `최고급 · 과학·기술 · 총 9개 · 2026-07-26`
- 인쇄 컬럼: `# / Word / 품사 / 난이도·주제 / 뜻·영영뜻(또는 빈칸) / 예문`
- CSV 컬럼: `No, Word, POS, 뜻, 영영뜻, 예문, 난이도, 주제, 외움, 즐겨찾기`

### 🎤 스피킹 / ✍️ 라이팅 / 📖 리딩 — 탭 분리 (386문항 · 320개 상세주제)

| 시험 | 문항 | 구성 |
|------|------|------|
| 🗣 **OPIc** | 138 | 기본 주제 · 여가활동 · 취미/관심사 · 운동 · 휴가/출장 · 돌발주제 · 경험 · 롤플레이 |
| 💼 **토익스피킹** | 17 | Q1-2 지문 읽기 · Q3-4 사진 묘사 · Q5-7 질문에 답하기 · Q8-10 표 보고 답하기 · Q11 의견 제시 |
| 🎓 **토플 스피킹** | 17 | 독립형(Task 1) 6 · 통합형(Task 2·3·4) 3 · **스피킹 템플릿 8** |
| ✍️ **토플 라이팅** | 14 | Integrated Writing 5 · Academic Discussion 7 · 라이팅 템플릿 2 |
| 📖 **토플 리딩** | 200 | 12개 학문 분야 실전 지문 180 + 문제 유형 10종 해설 + 빈출 지문 주제 10종 |

- **OPIc은 설문 상세주제 단위**로 정리 — 영화 보기, 공원 가기, 음악 감상, 요리, 반려동물, 헬스, 조깅, 요가, 자전거, 수영, 국내/해외 여행, 날씨, 교통, 은행, 재활용, 호텔 등
- 상세주제마다 **묘사 / 경험(과거) / 변화·비교(또는 문제 상황)** 3콤보 질문과 답변
- 롤플레이 8개 상황 × (정보 요청 + 문제 해결) 2세트
- **리딩**은 120~170단어 실전 지문 + 4지선다 문제 + 정답 근거 해설. 생물학·식물학·천문학·지질학·미국사·세계사·고고학·예술사·심리학·경제·환경·기술사 12개 분야 × 15문항, **문제 유형 10종 필터** 제공
- 리딩·라이팅 카드는 제목만 접혀 있고, 펼치면 지문 → 정답·해설 순서로 표시
- 각 문항마다: **영문 답변** · **한글 번역 토글** · **원어민 음성 재생(TTS)** · **핵심 표현 5개** · **고득점 팁**
- **🎤 스피킹 탭**(OPIc·토익스피킹·토플 스피킹) / **✍️ 라이팅 탭** / **📖 리딩 탭** 으로 분리
- 각 탭에서 시험 → 분류 → 상세주제 3단계 필터 + 통합 검색

공통: 🌙 다크 모드 · 📱 반응형 · ⌨️ 키보드 단축키

### 키보드 단축키

**플래시카드**
| 키 | 동작 |
|----|------|
| `Space` | 카드 뒤집기 |
| `←` `→` | 이전 / 다음 단어 |
| `Enter` | 외움 표시 후 다음으로 |

**퀴즈**
| 키 | 동작 |
|----|------|
| `1` `2` `3` `4` | 해당 번호 보기 선택 |
| `Enter` · `Space` · `→` | 다음 문제 (채점 후) |
| `Enter` | 결과 화면에서 다시 풀기 |

## 📝 데이터 추가/수정

**단어** — `words.js` 배열에 추가
`level`: 1=기초, 2=중급, 3=고급, 4=최고급 / `topic`: 위 13종 중 하나(정확히 일치해야 필터에 잡힘)
```js
{ word: "mitigate", pos: "v.", en: "to make less severe", ko: "완화하다",
  ex: "Trees can mitigate heat.", level: 2, topic: "변화·수량" }
```

**문항** — `speaking.js` 배열에 추가
(`exam`: `OPIc` | `TOEIC` | `TOEFL` | `TOEFL Writing` | `TOEFL Reading`)
```js
{ exam: "OPIc", category: "여가활동", topic: "영화 보기", question: "...", targetLevel: "IH–AL",
  answerEn: "...", answerKo: "...", keyExpressions: [{en:"...", ko:"..."}], tips: "..." }
```
지문·보기처럼 줄바꿈이 필요한 곳은 `\n`을 쓰면 화면에서 줄바꿈으로 표시됩니다.
